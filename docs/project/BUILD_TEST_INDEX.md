# Build / Test / Release Index

This file is the durable index for testable identities and evidence.

## Current identity scheme

- **Marketing version source**: `MARKETING_VERSION` in `ChatGPTClient.xcodeproj/project.pbxproj`.
- **Build number source**: `CURRENT_PROJECT_VERSION` in the same Xcode target settings.
- **Candidate ID**: `DEV-<work-slug>-<marketing-version>-b<build>`.
- **IPA artifact name**: `ChatGPTClient-<marketing-version>-b<build>-dev-<work-slug>.ipa`.
- **Artifact checksum**: SHA-256 sidecar generated by `scripts/build_ipa.sh`.
- **Package identity rule**: the actual built `Info.plist` Candidate/version/build and the emitted IPA filename must agree. Workflow Artifact container naming alone is not identity proof. `scripts/build_ipa.sh` must not override the Candidate with a stale per-Work default; it derives the package work slug from the built app metadata and fails on Candidate/version/build mismatch.

Every new testable Active task/candidate must allocate a unique candidate/build identity before artifact production. Do not reuse an exact build/candidate/artifact identity.
