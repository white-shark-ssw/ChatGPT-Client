## Current identity scheme

- **Marketing version source**: `MARKETING_VERSION` in `ChatGPTClient.xcodeproj/project.pbxproj`.
- **Build number source**: `CURRENT_PROJECT_VERSION` in the same Xcode target settings.
- **Candidate ID**: `DEV-<work-slug>-<marketing-version>-b<build>`.
- **IPA artifact name**: `ChatGPTClient-<marketing-version>-b<build>-dev-<work-slug>.ipa`.
- **Artifact checksum**: SHA-256 sidecar generated by `scripts/build_ipa.sh`.
- **Package identity rule**: actual built `Info.plist` Candidate/version/build and emitted IPA filename must agree. Workflow Artifact container naming alone is not identity proof. `scripts/build_ipa.sh` derives package identity from built app metadata and fails on mismatch.

Every new testable Active task/candidate must allocate a unique candidate/build identity before artifact production. Never reuse an exact build/candidate/artifact identity.
